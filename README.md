# 成人看護学・数値マスター Complete Edition

ブラウザで開けるクイズWebアプリです。

## 使い方
1. このリポジトリをブラウザで開く
2. `index.html` を開く
3. そのまま問題に回答

## GitHub Pagesで公開する場合
1. GitHubでこのリポジトリの Settings に移動
2. Pages を開く
3. Source を `Deploy from a branch` に設定
4. Branch を `main` / `/root` に選択
5. 保存して公開URLを確認

公開URLの形式例:
`https://picture0228-ux.github.io/nursing-quiz/`
